    59→### Files Created
    60→
    61→1. **`src/app/api/digital-products/orders/route.ts`** — POST handler for creating orders
    62→   - Zod validation: `{ productSlug, customerName (min 2), customerEmail (email) }`
    63→   - Does NOT accept amount, currency, price, or discount from client
    64→   - Looks up product via `getServerProduct` from server-catalog; returns 400 if not found/inactive
    65→   - Gets server-owned price via `getCheckoutData` — price determined by server, not client
    66→   - Currency from `STORE_CURRENCY` env (default "INR"); converts to smallest unit (cents/paise) × 100
    67→   - Creates pending order in database with `db.digitalProductOrder.create`
    68→   - Creates Razorpay order via `createRazorpayOrder`; updates local order with `razorpayOrderId`
    69→   - Returns safe checkout data: `{ orderId, razorpayOrderId, amount, currency, keyId }` — never exposes manipulatable price
    70→
    71→2. **`src/app/api/digital-products/verify/route.ts`** — POST handler for payment verification
    72→   - Zod validation: `{ orderId, razorpayOrderId, razorpayPaymentId, razorpaySignature }`
    73→   - Looks up local order; returns 404 if not found
    74→   - Verifies `razorpayOrderId` matches the one on the local order (mismatch → 400)
    75→   - Verifies payment signature via `verifyPaymentSignature` (HMAC-SHA256); invalid → 400
    76→   - Updates order: status → PAID, sets `razorpayPaymentId`, `razorpaySignature`, `paidAt`
    77→   - Calls `fulfilOrder` (generates download token + sends email; idempotent)
    78→   - Returns `{ success: true, orderId }`
    79→
    80→3. **`src/app/api/digital-products/order-status/route.ts`** — GET handler for order status
    81→   - Gets `orderId` from query params; returns 400 if missing
    82→   - Looks up order in database; returns 404 if not found
    83→   - If order is PAID and `fulfilmentSentAt` is set, generates download URL via `generateDownloadToken`
    84→   - Download URL: `/api/digital-products/download/[token]`
    85→   - Returns `{ status, productName, customerEmail, downloadUrl? }`; product name from config
    86→
    87→4. **`src/app/api/digital-products/webhook/razorpay/route.ts`** — POST handler for Razorpay webhooks
    88→   - Gets raw body as text (does NOT JSON parse before signature verification)
    89→   - Gets `X-Razorpay-Signature` header; verifies via `verifyWebhookSignature`
    90→   - Invalid signature → 400
    91→   - Parses JSON body after verification
    92→   - Idempotency: checks `paymentWebhookEvent.findUnique` on `eventId`; returns 200 if duplicate
    93→   - Stores event in `paymentWebhookEvent` table
    94→   - Handles event types using `after()` from `next/server` for non-blocking work:
    95→     - `payment.captured`: finds order by `razorpay_order_id`, marks PAID if not already, triggers fulfilment
    96→     - `payment.failed`: finds order, marks FAILED
    97→     - `refund.created` / `refund.processed`: finds order, marks REFUNDED, sets `refundedAt`
    98→   - Returns 200 promptly (doesn't hold response for email sending)
    99→
   100→5. **`src/app/api/digital-products/download/[token]/route.ts`** — GET handler for secure file download
   101→   - Gets token from route params
   102→   - Verifies token via `verifyDownloadToken` (HMAC-SHA256 signature + expiry check); invalid/expired → 403
   103→   - Looks up order by `orderId` from token payload; not found → 403
   104→   - Verifies order status is PAID; not paid → 403
   105→   - Verifies product entitlement: `productId` from token matches order's `productId`; mismatch → 403
   106→   - Increments `downloadCount` and sets `lastDownloadAt` on order
   107→   - Gets product file via `getSecureProductFile`; not found → 404
   108→   - Streams file as Response with headers:
   109→     - `Content-Type: application/zip`
   110→     - `Content-Disposition: attachment; filename="[product-name].zip"`
   111→     - `Cache-Control: no-store, no-cache, must-revalidate`
   112→   - Converts Node.js ReadStream to Web ReadableStream for streaming
   113→
   114→### Security Measures
   115→- Server-owned pricing: client never sends amount/price/discount
   116→- Zod validation on all inputs
   117→- HMAC-SHA256 signature verification for payments, webhooks, and download tokens
   118→- Webhook idempotency via event deduplication
   119→- Download token expiry (7 days) and product entitlement verification
   120→- `after()` for non-blocking fulfilment work in webhook handler
   121→- No internal error details exposed to client (generic error messages)
   122→- Path traversal protection inherited from product-storage.ts
   123→- Cache-Control headers prevent download URL caching
