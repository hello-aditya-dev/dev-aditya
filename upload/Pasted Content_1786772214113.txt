# RAZORPAY INTEGRATION

Use the CURRENT official Razorpay Standard Checkout documentation at implementation time.

Do not implement payment handling from memory.

The architecture must satisfy these principles:

1. create a Razorpay Order SERVER-SIDE;
2. server determines the product and amount;
3. never trust browser-supplied price;
4. pass server-generated `order_id` into Checkout;
5. Razorpay Checkout opens only after customer action;
6. verify payment signature SERVER-SIDE;
7. use the server-owned original order ID for signature verification;
8. confirm payment/capture state before fulfilment;
9. implement signed Razorpay webhooks;
10. make fulfilment idempotent;
11. never expose Razorpay Key Secret;
12. never expose webhook secret.

# RAZORPAY WEBHOOK
